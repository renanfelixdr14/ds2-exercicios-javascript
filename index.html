Fundamentos da Web

Página Estática

Definição: É uma página cujos arquivos (HTML, CSS e JavaScript) já estão prontos e salvos no servidor. Quando o usuário acessa, o servidor apenas envia esses arquivos exatamente como estão, sem realizar nenhum processamento de dados. O conteúdo entregue é o mesmo para todos os visitantes.

Exemplo Real: O site de documentação de uma linguagem de programação, uma landing page promocional (sem sistema de login) ou o site de portfólio de um profissional.

Página Dinâmica

Definição: É uma página que não existe pronta no servidor, mas é gerada sob demanda. Quando o usuário faz a requisição, o servidor executa regras de negócio, geralmente consulta um banco de dados e "monta" o HTML na hora antes de enviar a resposta.

Exemplo Real: O feed de notícias do Instagram, o carrinho de compras da Amazon, a Netflix ou o seu dashboard do banco.

O Caminho Básico da Informação

  1. Navegador (Requisição): O usuário digita uma URL (ou clica em um link). O navegador atua como cliente e envia uma requisição HTTP para a internet, que é roteada até o servidor onde o site está hospedado.
  2. Servidor (Processamento): O servidor recebe o pedido. Se for uma página estática, ele simplesmente localiza o arquivo HTML. Se for uma página dinâmica, o servidor roda scripts, comunica-se com o banco de dados e constrói o documento final.
  3. Resposta (Renderização): O servidor devolve uma resposta HTTP contendo o código (HTML, CSS, JS) para o navegador. O navegador interpreta esse código e desenha (renderiza) a interface gráfica na tela do usuário.
